# ALG Style Assistant

Build a modern, professional and responsive web application called “ALG Collections AI Business Assistant” for ALG Collections, a clothing business.

The purpose of the application is to help ALG Collections manage repetitive business tasks using AI, improve customer service, create marketing content, manage product information and plan daily business activities.

The application should have a modern fashion/e-commerce-inspired design using the ALG Collections brand identity. Use a clean, elegant colour palette such as black, white/cream and gold. Include the ALG Collections logo in the header/dashboard where appropriate.

MAIN FEATURES:

1. AI Product Description & Marketing Generator

Create a form where the business owner can enter product information, including:

- Product name

- Product category

- Description

- Price

- Available sizes

- Available colours

- Material/fabric (optional)

- Available stock (optional)

- Target customer

- Special offer or promotion (optional)

The AI should generate:

- Professional product descriptions

- Instagram captions

- Facebook posts

- WhatsApp promotional messages

- Short product advertisements

- Relevant hashtags

The user must be able to edit and copy the AI-generated content before using it.

Do not allow the AI to invent prices, sizes, colours, stock availability or other product information that was not provided.

2. AI Customer Response Generator

Create a feature that helps ALG Collections respond to customer messages.

The user should be able to paste a customer's message and select a response type, such as:

- Product enquiry

- Price enquiry

- Size enquiry

- Colour enquiry

- Stock availability

- Delivery enquiry

- Order enquiry

- Complaint

- General enquiry

The AI should generate a friendly, professional and concise response.

The response should only use information provided by the business. If information is missing, the AI should recommend that the business owner confirm the information instead of making up an answer.

Allow the user to edit and copy the response.

3. AI Business Task Planner

Create an AI task planner for ALG Collections.

The user should be able to enter their tasks for the day or week.

The AI should:

- Organise tasks by priority

- Identify urgent and important tasks

- Create a daily or weekly schedule

- Suggest realistic time allocations

- Include tasks such as responding to customers, posting on social media, checking stock, processing orders, marketing and administration

- Allow the user to mark tasks as completed

4. AI Social Media Content Generator

Create a social media content tool specifically for ALG Collections.

Allow the user to select:

- Platform: Instagram, Facebook or WhatsApp

- Content type: Product promotion, new arrival, sale, customer appreciation, restock or general brand post

- Tone: Professional, friendly, trendy or persuasive

The AI should generate platform-appropriate content with a clear call to action.

5. AI Customer Chatbot

Create a simple chatbot interface for ALG Collections.

The chatbot should answer common customer questions about:

- Products

- Prices

- Sizes

- Colours

- Availability

- Orders

- Delivery

- General business enquiries

The chatbot must only use information available in the product/business information provided by the user. If it does not know the answer, it should clearly say that the information needs to be confirmed by ALG Collections.

PRODUCT CATALOGUE:

Create a simple product management section where the business owner can add, edit and remove products.

Each product should have fields for:

- Product name

- Category

- Price

- Sizes

- Colours

- Material

- Stock quantity

- Product description

- Product image

- Optional notes

Make sizes and colours flexible so the business owner can enter different options for different clothing items. For example, one product may have S, M, L and XL while another may have XS to XXL.

DASHBOARD:

Create a modern dashboard showing:

- Total products

- Products in stock

- Low-stock products

- Recent customer enquiries

- Today's tasks

- Quick access buttons for the AI tools

NAVIGATION:

Use a sidebar navigation with:

- Dashboard

- Product Catalogue

- AI Product Generator

- Customer Responses

- Social Media Generator

- Task Planner

- AI Chatbot

- Settings

DESIGN:

Make the interface modern, clean, elegant and suitable for a fashion/clothing brand.

Use:

- Black

- Cream/white

- Gold accents

Use clear typography, cards, buttons and icons.

Make the application fully responsive and easy to use on both desktop and mobile devices.

RESPONSIBLE AI:

Include a visible Responsible AI disclaimer explaining that AI-generated information and content should be reviewed by a human before being sent to customers or published.

The AI must:

- Not invent product information

- Not make up prices or stock availability

- Not provide misleading information

- Clearly indicate when information is unavailable

- Keep the business owner in control of final decisions

AI OUTPUTS:

All AI-generated responses should be displayed in editable text boxes with options to:

- Edit

- Regenerate

- Copy

- Clear

Create realistic sample product data for demonstration purposes, but clearly label it as sample/demo data.

The application should feel like a real AI-powered productivity assistant for ALG Collections rather than a generic clothing website.Update the ALG Collections AI Business Assistant to use the official ALG Collections logo and brand colour palette.

BRAND IDENTITY:

Business name: ALG Collections

Use the uploaded ALG Collections logo as the official brand logo throughout the application.

Do not redesign, distort, crop, recolour or replace the logo.

Place the logo prominently in the dashboard header and sidebar/navigation.

BRAND COLOURS:

Primary:

- Black: #111111

- Champagne Gold: #C9A227

- Cream: #F8F3EA

Secondary:

- Soft Beige: #E8DCCB

- Blush Nude: #D8B7A5

DESIGN STYLE:

Create a sophisticated, elegant and modern fashion-boutique aesthetic.

Use:

- Black for headings, primary text and navigation

- Cream as the main background

- Champagne gold for buttons, icons, borders, highlights and important accents

- Soft beige for cards and secondary sections

- Blush nude sparingly for subtle decorative accents

Keep the design clean and premium. Avoid using bright colours, neon colours or excessive gradients.

The overall visual identity should communicate:

- Luxury

- Fashion

- Elegance

- Femininity

- Professionalism

- Modern clothing boutique

LOGO USAGE:

Use the uploaded ALG Collections logo wherever appropriate, especially:

- Login/welcome screen

- Dashboard

- Sidebar

- Header

- AI assistant pages

Make sure the logo remains clear and readable on both desktop and mobile.

Create consistent buttons, cards, forms, navigation and AI-generated content areas using the ALG Collections brand colours.

The website should look like a professional branded business application rather than a generic AI dashboard.
